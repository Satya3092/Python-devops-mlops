## Task 1 — Easy: Even or odd number of replicas

**Problem statement:** Given `replicas = 7`, print the remainder of dividing by 2 and explain if the number is even (remainder 0) or odd.

**Input requirements:** No user input required.

**Expected behavior:** Prints `7 % 2 = 1` and that it is odd.

**Expected output:**

```text
7 % 2 = 1
Odd
```

## Task 2 — Medium: Seconds formatter

**Problem statement:** Convert `backup_duration = 9876` seconds into hours, minutes and seconds using `//` and `%` (or divmod).

**Input requirements:** No user input required.

**Expected behavior:** Prints `2 h 44 m 36 s`.

**Expected output:**

```text
2 h 44 m 36 s
```

## Task 3 — Practical Challenge: Monthly AWS cost estimate

**Problem statement:** An EC2 instance costs $0.0416/hour, an EBS volume 100 GB at $0.08 per GB-month, and data transfer 250 GB at $0.09/GB. Calculate the monthly cost (730 hours), the yearly cost, and how many whole instances fit into a $200 monthly budget.

**Input requirements:** No user input required.

**Expected behavior:** Prints the monthly total, yearly total (2 decimals) and the instance count.

**Expected output:**

```text
EC2: 30.37 EBS: 8.0 Transfer: 22.5
Monthly total: $ 60.87
Yearly total: $ 730.42
Instances within $200/month: 6
```

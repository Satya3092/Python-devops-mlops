## Task 1 — Easy: First and last

**Problem statement:** Given `region = "ap-south-1"`, print the first character, the last character and the character at index 3.

**Input requirements:** No user input required.

**Expected behavior:** Prints `a`, `1`, `s`.

**Expected output:**

```text
a
1
s
```

## Task 2 — Medium: Initials

**Problem statement:** Given `first = "Linus"` and `last = "Torvalds"`, print the initials `L.T.` using indexing.

**Input requirements:** No user input required.

**Expected behavior:** Prints `L.T.`

**Expected output:**

```text
L.T.
```

## Task 3 — Practical Challenge: Permission decoder

**Problem statement:** Given `perm = "drwxr-xr--"`, print whether it is a directory, and for owner/group/others whether they can read, write and execute (use indexes 1–9).

**Input requirements:** No user input required.

**Expected behavior:** Prints a small permission report.

**Expected output:**

```text
Directory: True
owner read: True write: True execute: True
group read: True write: False execute: True
others read: True write: False execute: False
```

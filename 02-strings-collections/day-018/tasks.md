## Task 1 — Easy: Extract the extension

**Problem statement:** Given `filename = "backup-2026-11-20.tar.gz"`, print the last 6 characters and the date part (characters 7–16).

**Input requirements:** No user input required.

**Expected behavior:** Prints `tar.gz` and `2026-11-20`.

**Expected output:**

```text
tar.gz
2026-11-20
```

## Task 2 — Medium: Palindrome check

**Problem statement:** Check whether `"level"` and `"deploy"` are palindromes using slicing.

**Input requirements:** No user input required.

**Expected behavior:** Prints True for level and False for deploy.

**Expected output:**

```text
level is palindrome: True
deploy is palindrome: False
```

## Task 3 — Practical Challenge: Mask a secret

**Problem statement:** Given an API key `"AKIAIOSFODNN7EXAMPLE"`, print it masked so only the first 4 and last 4 characters are visible, with `*` in between (same total length).

**Input requirements:** No user input required.

**Expected behavior:** Prints `AKIA************MPLE`.

**Expected output:**

```text
AKIA************MPLE
```
